# Nashwan Catering Services — Premium Homepage

A luxury, high-end banquet catering homepage crafted for **Nashwan Catering Services**, matching the reference design layout with precision.

## 🌟 Key Design & Architectural Highlights

- **Visual Fidelity & Composition**: Features the banquet buffet hall hero background with golden chafing dishes, marble counters, floral vases, and ambient chandeliers on the right, paired with a subtle dark left-to-right gradient for typography legibility.
- **Official Brand Assets**: Embeds the authentic gold-and-ivory **Nashwan Catering** logo along with direct calling numbers (`9492247495` & `9949390829`).
- **Typography**: Combines *Playfair Display* & *Cinzel* serif headings with clean *Plus Jakarta Sans* body text.
- **Color Palette**: Royal Black (`#080706`), Champagne Gold (`#D4AF37`, `#ECC870`), and Ivory (`#FDFBF7`).
- **Service Highlights**: 4 horizontal features (*Events & Celebrations*, *Customized Menus*, *Fresh & Hygienic*, *Professional Team*) with gold outline icons and thin vertical gold dividers.
- **Statistics Panel**: Bottom-left rounded rectangular panel with thin gold borders, decorative laurel wreath emblems, gold serif figures (*500+ Events Catered*, *50+ Menu Options*, *99% Client Satisfaction*).
- **Interactive Modals**:
  - **Book Your Event / Book Now**: Reservation dialog with date picker, guest count selection, cuisine options, and direct WhatsApp sync.
  - **Custom Menu Curator**: Interactive course selector allowing clients to build bespoke menus and calculate dishes.
  - **Signature Menus**: Detailed courses for Nizami Shahi Dastarkhwan, Grand Wedding spreads, and Pure Vegetarian banquets.
  - **Banquet Gallery**: High-resolution imagery of table settings, live degh counters, and dessert displays.

## 🚀 How to Run & Preview

### Option 1: Double-Click Standalone Preview (No Server Required)
Simply double-click `preview.html` or `dist/index.html` in Windows Explorer to open and use the fully interactive site immediately in any web browser.

### Option 2: Run Development Server (Vite)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Production Build
```bash
npm run build
```
Built files are located in the `dist/` directory ready for deployment.
